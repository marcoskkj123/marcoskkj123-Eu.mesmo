# 📖 Sobre

O Snake Game é uma recriação do famoso jogo da cobrinha. O objetivo é controlar a cobra, comer a comida para aumentar sua pontuação e evitar bater nas paredes ou em si mesma.

---

# ✨ Funcionalidades

- 🐍 Movimentação suave
- 🍎 Comida gerada aleatoriamente
- 📈 Sistema de pontuação
- 💀 Game Over
- 🔄 Reiniciar partida
- 🎹 Controles pelo teclado
